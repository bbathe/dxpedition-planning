# Lookups for a shortlist

Check the live page. Cite the URL and the date. If a page is gone, find the current list and cite that URL instead.

| Question | Where to look |
|----------|----------------|
| Is it a current DXCC entity? | ARRL DXCC entities list |
| How needed is it? | Club Log DXCC Most Wanted. Record the rank and the list date. Skip the rank if the list cannot be opened. |
| Recent activation? | Club Log or a dated DXpedition report the user trusts. |
| Entry, visa, security | Official immigration page, plus a government travel advisory. Restate the constraint; do not soften a prohibition. |
| Flights and gateways | An airline or airport source for the user's departure airport. If the airport is unknown, name the entity gateway only. |
| Lodging | A property, ship, or field-camp source. "Hotels exist in the capital" is not a lodging plan. |
| License | The administration that issues amateur licenses for that entity. Status stays `TBD` until an application exists. |

Out of scope unless the user asks: IOTA, POTA, SOTA, and deleted DXCC entities.

Access that requires operating without a license, landing where landing is prohibited, or ignoring an entry rule is not a candidate. Put it on the impractical list.

When the user picks one, copy only sourced facts into that expedition's `plan.md` and `logistics.md`. Map travel into "Travel to the entity" and lodging into "Site / lodging". Unchecked items stay `TBD`.
