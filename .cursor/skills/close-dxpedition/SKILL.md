# Close a DXpedition

## Start

1. Identify the expedition folder and read `README.md`, `qsl.md`, and `operating.md`.
2. Set README status to `closed` only when the user says the operation is over. Use `cancelled` if it did not take place.

## Logs and QSL

Update `qsl.md` with what actually happened:

- ADIF path, if the user gives one, and whether they checked duplicates
- LoTW: not started, uploaded, or confirmed — only as the user reports
- Club Log: same
- OQRS, bureau, direct, or manager: match the written QSL policy; note exceptions

Do not invent QSO totals. If you state a total, name the file or the user message it came from. Do not upload logs, buy certificates, or send cards unless the user asks.

## After action

Fill `after-action.md`:

- UTC dates actually on the air
- Callsign used
- QSO total and source, or `TBD`
- What worked
- Gear, power, or logging failures
- Follow-ups (QSL, thank-yous, repairs), each with an owner

Leave praise and publicity out. Facts and follow-ups only.
